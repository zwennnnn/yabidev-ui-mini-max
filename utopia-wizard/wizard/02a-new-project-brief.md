## Extraordinary Direction

Pick 2 or 3. Do not pick everything.

```text
1. Break expected layout
Navigation and sections become part of the composition instead of predictable top-left/top-right structure.

2. Break hero expectations
No default hero image reflex. Use typography, negative space, scale, rhythm, or a single focused visual decision.

3. Fake-out ending
Create a quiet near-ending, then reveal a final unexpected closing scene.

4. Brand cursor
Cursor behavior becomes part of the identity, with section-aware shape or behavior.

5. Deliberate silence
One section stops all motion and uses stillness as emphasis.

6. Breaking the frame
An element visibly crosses section or viewport boundaries.

7. Unusual scroll feel
One section changes scroll physics: horizontal, breathing, compression, speed-ramp, or other controlled 2D response.
```

For each selected direction, explain why it fits the project. A strange effect without a reason is not art direction.
